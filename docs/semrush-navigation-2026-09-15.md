# SEO Command report navigation

The September 2026 signed-in Semrush dashboard, Domain Overview and AI Visibility screens were used as visual references. SEO Command retains its orange identity, original chart palette and Manrope font.

Eight toolkit destinations (Home, SEO, AI, Traffic & Market, Local, Content, Reports and Tasks) use a slim icon rail and a full-name tool sidebar. Desktop can collapse the second column; mobile uses the same grouping in a drawer. Tools are searchable through the existing global search.

Report views use URL parameters, retaining website and reporting period through tool changes and Back/Forward. Existing saved routes remain supported, including research feature hashes, platform comparison and business-management anchors. Navigation tests cover destinations, toolkit ownership and site switching.

The website overview uses paired AI and SEO summaries followed by tracking, audit, local and link cards. Page coverage, urgent actions, Scan Centre and the detailed saved Search Console/Analytics charts remain available. All headline values use existing read models; samples, date coverage and measured vs estimated data remain labelled.

Content production is now available after the page loads, with direct writing, brief and editorial-schedule views. Dynamically added websites use their managed Google connection rather than a static website list. Invalid authority scores are displayed as unavailable when component evidence is missing.

## Explicit data gaps

Autocomplete collection and competitor total-traffic collection are not implemented by this UI change. Their layouts are visible with unavailable states. Country-level AI mentions, historical domain traffic and other absent provider metrics also retain their spaces without invented values. Existing Domain Overview organic estimates are not treated as total traffic. Proprietary Semrush scores are not reproduced or substituted with internal scores.

No database migrations, snapshot writes, provider changes, budget changes or collection jobs are part of this release. Browser verification uses isolated synthetic data without a production database or provider credentials.
